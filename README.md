# my-electron-app
cross-platform desktop app with electron

References:
* [Tutorial](https://www.electronjs.org/docs/latest/tutorial/tutorial-first-app)


## 1. Setup
```shell
$ npm i -g yarn@latest
$ npm i -g --allow-scripts=yarn

$ yarn -v
$ mkdir my-electron-app
$ cd my-electron-app/
$ yarn init
$ cat package.json 
$ yarn add electron --dev
$ yarn run start
```
